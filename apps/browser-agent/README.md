# MboQara browser application agent

This Chrome/Chromium extension is the browser-side half of the application
workflow. It only operates a run that the candidate has already prepared,
reviewed, and approved in MboQara.

## What it does

- claims the oldest approved application run for the paired candidate;
- inspects and fills the employer form in the frame already open inside
  MboQara;
- uploads the tailored resume and cover letter;
- stops for CAPTCHAs, sign-in, MFA, legal attestations, missing required
  fields, and unexpected confirmation states;
- reports each step back to the API so the run has an audit trail.

It never bypasses a CAPTCHA and it never accepts legal terms on the
candidate's behalf.

## Install locally

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this directory.
4. Open the extension's options page.
5. Enter the API address (`https://api.mboqara.angisoft.co.ke/v1` for the
   hosted API) and the one-time pairing code generated by MboQara.

The extension requests access to pages because the employer's application may
be an embedded cross-origin frame. The permission is used only for the
approved run and the pages belonging to its allowed host.
